# Project agent guidelines

These instructions apply throughout the repository, including backend and frontend.
Also follow the `AGENTS.md` in the area you change.

- Before coding, read and apply [Ponytail](skills/ponytail/SKILL.md) in `full` mode,
  unless the user chooses another mode or disables it. Reuse existing code and
  platform features; make the smallest complete, readable change.
- Preserve the user's requirements and accepted design plans. Simplicity must not
  remove required behavior, validation, security, accessibility or quality checks.
- For requested change reviews, use [ponytail-review](skills/ponytail-review/SKILL.md).
  For requested repository audits, use [ponytail-audit](skills/ponytail-audit/SKILL.md).
- Use [ponytail-debt](skills/ponytail-debt/SKILL.md),
  [ponytail-gain](skills/ponytail-gain/SKILL.md) and
  [ponytail-help](skills/ponytail-help/SKILL.md) when requested.

The skills are project-local instructions, shared by both stacks. User instructions
and project-specific guidelines take precedence over generic skill advice. See
[the skills notes](skills/README.md) for source and update details.
