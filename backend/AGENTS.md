# Agent Notes

Apply the shared [project guidelines and Ponytail skills](../AGENTS.md).

Prioritize clean, readable, simple code.

- Prefer clarity and maintainability over cleverness or micro-optimizations.
- Keep classes, methods, and data objects focused on one responsibility.
- Split larger logic into small, named pieces that are easy to read, test, fix, and reuse.
- Follow the existing Spring Boot structure and naming style before introducing new patterns.
- Use explicit, understandable names for services, DTOs, methods, and variables.
- Add comments only when they clarify non-obvious behavior or important business rules.
- Keep changes scoped to the requested behavior unless a small cleanup is needed to make the change clear.
