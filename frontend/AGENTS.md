# Agent Notes

Prioritize clean, readable, simple code.

- Prefer clarity and maintainability over cleverness or micro-optimizations.
- Keep components, hooks, helpers, and styles focused and easy to scan.
- Split larger UI logic into small, named pieces that are easy to read, fix, test, and reuse.
- Follow the existing React and CSS style before introducing new patterns.
- Use explicit, understandable names for components, props, state, and helper functions.
- Keep visual and state logic separated when it makes the code easier to reason about.
- Add comments only when they clarify non-obvious behavior or important interaction rules.
- Keep changes scoped to the requested behavior unless a small cleanup is needed to make the change clear.
